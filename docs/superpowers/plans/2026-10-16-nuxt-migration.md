# Nuxt Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move redwoodlabs.dev from Vue + Vite (`vite-ssg`) to a statically generated Nuxt 4 site with Markdown content collections, with zero visible or SEO regressions on the homepage.

**Architecture:** Nuxt 4 (`app/` directory) built with `nuxt generate` into `.output/public`. `@nuxt/content` v3 holds `projects` and `blog` Markdown collections; pages are generated by Nitro's link crawler starting at `/`, so routes that nothing links to are never generated. SEO tags come from `useSeoMeta`/`useHead`, structured data from `nuxt-schema-org`, and `robots.txt`/`sitemap.xml` from `@nuxtjs/robots` and `@nuxtjs/sitemap`. Tests are Node's built-in test runner asserting on the generated static output.

**Tech Stack:** nuxt 4.x, @nuxt/ui 4.x, @nuxt/content 3.x, @nuxtjs/sitemap, @nuxtjs/robots, nuxt-schema-org, Node 22 (`node:test`), pnpm.

**Spec:** `docs/superpowers/specs/2026-10-16-nuxt-migration-design.md`

`tests/lib/html.mjs`:

```js
export const OUT = new URL('../../.output/public/', import.meta.url)

function metaContent(html, attr, key) {
  const tag = html.match(new RegExp(`<meta[^>]*\\b${attr}="${key}"[^>]*>`, 'i'))?.[0]
  return tag?.match(/\bcontent="([^"]*)"/i)?.[1] ?? null
}

function jsonLdBlocks(html) {
  return [...html.matchAll(/<script[^>]*type="application\/ld\+json"[^>]*>([\s\S]*?)<\/script>/gi)]
    .map((m) => JSON.parse(m[1]))
}

export function normalizePerson(blocks) {
  const nodes = blocks.flatMap((b) => (b['@graph'] ? b['@graph'] : [b]))
  const byId = new Map(nodes.filter((n) => n['@id']).map((n) => [n['@id'], n]))
  const resolve = (v) => (v && typeof v === 'object' && v['@id'] && Object.keys(v).length === 1 ? byId.get(v['@id']) ?? v : v)
  const first = (v) => (Array.isArray(v) ? v[0] : v)
  const isPerson = (n) => [].concat(n['@type']).includes('Person')
  const p = nodes.find(isPerson)
  if (!p) return null
  const image = resolve(first(p.image))
  const worksFor = resolve(first(p.worksFor))
  const address = resolve(first(p.address)) ?? {}
  return {
    name: p.name,
    url: p.url,
    image: typeof image === 'string' ? image : image?.url ?? image?.contentUrl,
    jobTitle: p.jobTitle,
    worksFor: worksFor?.name,
    address: { locality: address.addressLocality, region: address.addressRegion, country: address.addressCountry },
    sameAs: [].concat(p.sameAs ?? []),
  }
}

export function extractHead(html) {
  return {
    title: html.match(/<title>([^<]*)<\/title>/i)?.[1] ?? null,
    description: metaContent(html, 'name', 'description'),
    canonical: html.match(/<link[^>]*rel="canonical"[^>]*>/i)?.[0].match(/href="([^"]*)"/)?.[1] ?? null,
    og: Object.fromEntries(['title', 'description', 'type', 'url', 'image'].map((k) => [k, metaContent(html, 'property', `og:${k}`)])),
    twitter: Object.fromEntries(['card', 'title', 'description'].map((k) => [k, metaContent(html, 'name', `twitter:${k}`)])),
    person: normalizePerson(jsonLdBlocks(html)),
  }
}

export function visibleText(html) {
  const body = html.match(/<body[^>]*>([\s\S]*)<\/body>/i)?.[1] ?? ''
  return body
    .replace(/<script[\s\S]*?<\/script>/gi, ' ')
    .replace(/<style[\s\S]*?<\/style>/gi, ' ')
    .replace(/<!--[\s\S]*?-->/g, ' ')
    .replace(/<[^>]+>/g, ' ')
    .replace(/&amp;/g, '&').replace(/&#39;|&apos;/g, "'").replace(/&quot;/g, '"').replace(/&nbsp;/g, ' ')
    .replace(/\s+/g, ' ')
    .trim()
}
```

export function hasBody(doc: { body?: { value?: unknown[] } | null }): boolean {
  const nodes = doc.body?.value ?? []
  return nodes.some((n) => (typeof n === 'string' ? n.trim() !== '' : true))
}
